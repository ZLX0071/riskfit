# 面试双话术卡

> 同一个产品，对不同面试官换开场重点。底层数字与事实完全一致，变的只是叙事主角。

## AI 公司版（AI PM / AI Agent 岗）

**开场 30 秒**：
"我做了 RiskFit，一个组合风险体检工具。它最想回答的问题是：AI 生成的金融内容怎么让人敢信？我的做法是**计算与叙述分离**——所有数字由代码算，LLM 只负责解释，Prompt 层禁止它碰算术，生成之后还有一道程序化校验：报告里出现的每个数字都必须能在引擎输出里找到，找不到就重试、再不行就回退到确定性模板。所以这个产品的报告永远可溯源、永不空白。这不是口号，是三层工程机制。"

**追问弹药**：
- 为什么不让 LLM 直接算？→ 幻觉在金融场景的代价不对称：错的解释浪费一次阅读，错的数字毁掉全部信任。
- 校验怎么做的？→ 引擎数字序列化成多精度白名单 + 报告全文数字提取逐一对照；结构校验（3 风险点+3 自查）先行。
- 如果模型输出格式坏了？→ JSON parse 失败计入失败次数，重试 ≤2，之后模板兜底——用户永远看到一份完整报告。
- 体质分怎么防"黑盒感"？→ 权重和分档全公开，明说这是可迭代的 PM 决策。

## Fintech / Crypto 公司版

**开场 30 秒**：
"我做了 RiskFit，因为香港散户的钱散在两三个平台——券商工具管不到 crypto，crypto 记账 app 算不了风险，没人帮他们把组合放在一起看。RiskFit 输入港美股+crypto 持仓，30 秒出一份说人话的风险报告：波动率、最大回撤、历史模拟法 VaR、集中度，外加三个用真实历史窗口算的压力情景——2008 股灾、2022 币灾、主导资产腰斩。定位是风险教育：给风险提示和自查问题，不给买卖建议，SFC 的牌照红线我从一开始就设计进去了。"

**追问弹药**：
- 和 moomoo AI 组合体检的区别？→ moomoo 服务自家客户、只管自家生态；RiskFit 服务"资产散落在多平台、含 crypto"的用户，免登录不要求开户（详见 docs/competitive-analysis.md）。
- 2008 情景里 BTC 怎么办？→ 代理规则：直接套用其 2022 真实收益、不放大，方法论脚注里主动交代局限——被问出来不如自己讲出来。
- 数据哪来的、断了怎么办？→ Yahoo + Binance 免费接口，三级兜底（缓存→实时→内置真实快照），断网也能完整演示。
- 商业化？→ V1 是 To C 工具做信任；低频工具的现实路径是 C 端起量、B 端变现（白标给券商/顾问），但眼下只关心一件事：用户信不信这份报告。

## 通用底线

- 用户调研怎么做的？→ "求职时效紧，我先用 6 个假设画像推演需求（文档里明确标注不是真实用户），上线后用真实用户测试验证关键假设——重点验证集中度盲区和 AI 信任两条洞察。"（诚实标注比伪装真实调研经得起追问）
- 为什么 V1 砍了那么多？→ 求职时效 + PM 作品比判断力不比功能量；被砍的委员会/穿越沙盘都在 Roadmap 里带着理由（见 docs/decision-log.md D-02）。
