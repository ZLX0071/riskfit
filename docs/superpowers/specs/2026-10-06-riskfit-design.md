# RiskFit（风险体检台）设计方案

- 日期：2026-10-06
- 状态：待用户确认
- 类型：全新项目（作品集：AI PM / fintech PM / crypto PM 实习面试用）

## 1. 背景与目标

用户正在 HK 求职 AI PM / AI Agent 实习，需要一个 risk analysis 主题的作品集项目，服务面试演示与简历。

成功标准：

1. 一周内上线可公开访问的 demo；
2. 面试现场 ≤3 分钟完整演示，且**断网/接口故障也能演示**（兜底数据）；
3. README 能讲清三大设计决策：计算与叙述分离、风险评分卡设计、合规边界处理；
4. 提供两套面试开场话术（AI 公司版 / fintech·crypto 公司版）。

非目标：真实用户运营、盈利、投研级别的数据准确性承诺。

## 2. 产品定位

一句话：散户输入自己的持仓组合，30 秒拿到一份"说人话"的风险体检报告。

- 目标用户：有一定持仓（港美股 + crypto）但看不懂风险指标的年轻人。
- 产品边界：风险教育工具；页面固定声明"本报告为风险教育内容，不构成投资建议"。

## 3. 用户流程（4 屏）

1. **落地页**：一句话价值主张 + "一键填入示例组合"（腾讯 + AAPL + BTC）。
2. **组合编辑**：从约 16 个预置热门资产中点击选择，或手动输入代码兜底；每个持仓输入市值；持仓数 2–8 个。
3. **体检中**：三步进度展示（获取行情 → 计算指标 → AI 撰写报告）。
4. **体检报告**（从上到下）：
   - 风险体质分（1–10）+ 一句话总评；
   - 指标卡：年化波动率、最大回撤、VaR(95%)、持仓集中度，各附基准对照（vs 恒指 / 标普 500）；
   - 资产相关性热力图；
   - 压力情景卡 ×3：各显示预估亏损百分比与金额；
   - AI 报告正文：三个主要风险点 + 三个自查问题；
   - 方法论脚注（含压力情景代理规则与局限）；
   - AI 声明区（折叠）："数字由计算引擎产生，AI 仅负责解释" + 免责声明。

## 4. V1 功能范围

**做**：上述 4 屏；5 项指标；3 个压力情景；基准对照；数据缓存与演示兜底；错误态。

**不做（YAGNI）**：登录与数据库、期权/衍生品、自由代码搜索、多语言切换、分享卡片（v1.5）、超过 3 个情景、超过 8 个持仓。

## 5. 数据与计算引擎

### 5.1 数据源与预置资产

- 港美股：Yahoo Finance 日频，近 2 年；基准指数 ^HSI（恒指）、^GSPC（标普 500）。
- Crypto：Binance 公开 K 线接口（免费、无需密钥、全历史日 K）；支持 BTC、ETH、SOL；CoinGecko 仅作备用。
- 取数窗口：指标计算用近 2 年（crypto 近 365 天）；压力情景按各自窗口（2007–2009、2022）另行取数，Yahoo 与 Binance 均支持全历史。
- 预置资产清单：0700.HK 腾讯、9988.HK 阿里、0005.HK 汇丰、1299.HK 友邦、3690.HK 美团、1810.HK 小米、AAPL、MSFT、NVDA、TSLA、AMZN、GOOGL、SPY、BTC、ETH、SOL。

### 5.2 对齐与货币

- 组合收益率序列按港美共同交易日对齐；crypto 在缺失交易日沿用最近可得价格。
- 单资产指标用各自完整窗口（crypto 年化用 √365，股票用 √252）；组合层面指标用对齐序列（√252），脚注说明口径差异。
- 金额统一以 USD 输入（UI 提示按市价折算）；所有金额类输出以 USD 计；百分比为主、金额为辅。

### 5.3 指标口径

| 指标 | 口径 |
|---|---|
| 年化波动率 | 对齐组合日收益标准差 × √252 |
| 最大回撤 | 对齐序列内峰谷最大跌幅 |
| VaR(95%, 1日) | 历史模拟法：对齐组合日收益的 5% 分位 × 组合市值 |
| 集中度 | 第一大持仓权重（主）+ HHI（辅） |
| 相关性 | 对齐日收益的皮尔逊相关矩阵 |
| 基准对照 | 组合年化波动率 vs ^HSI / ^GSPC 同期，输出倍数 |

### 5.4 压力情景（含代理规则）

1. **2008 级股灾**（窗口 2007-10 ～ 2009-03）：窗口内有数据的资产用真实历史收益；crypto 在该窗口无数据，代理规则＝直接套用其 2022 窗口的真实收益（不额外放大）。
2. **2022 币灾**（窗口 2022-01 ～ 2022-12）：全部资产用真实历史收益。
3. **主导资产腰斩**：最大持仓 -50%，其余资产按 `corr × (σ_i / σ_主导) × -50%` 线性联动。

每个情景输出组合预估亏损百分比与金额。报告脚注明示代理规则，并说明"线性联动的局限"。

### 5.5 风险体质分（评分卡）

1–10 分，10 = 极高风险。五个指标按分档打 1–10 分后加权：波动率 25% / 最大回撤 20% / VaR 20% / 集中度 20% / 平均两两相关性 15%。档内线性插值。

| 指标 | 1–2 分 | 3–4 分 | 5–7 分 | 8–10 分 |
|---|---|---|---|---|
| 年化波动率 | <15% | 15–25% | 25–40% | >40% |
| 最大回撤（窗口内） | <15% | 15–30% | 30–50% | >50% |
| VaR(95%, 1日, 占组合) | <1% | 1–2% | 2–4% | >4% |
| 第一大持仓权重 | <25% | 25–40% | 40–60% | >60% |
| 平均两两相关性 | <0.2 | 0.2–0.4 | 0.4–0.6 | >0.6 |

单持仓组合不允许（最少 2 个），避免集中度与相关性退化。

## 6. AI 层设计（计算与叙述分离）

- 输入：计算引擎输出的结构化 JSON（全部指标、情景结果、基准倍数、体质分明细）。
- 生成方：GLM API（用户现有额度）。生成内容：总评一句话、三个主要风险点、三个自查问题。
- Prompt 约束：只能引用 JSON 中已有的数字；禁止计算新数字；禁止出现买卖建议措辞；输出结构化 JSON。
- 后校验：提取输出中的所有数字，与输入 JSON 对照（允许四舍五入容差）；不通过则重试（≤2 次）；仍失败则回退到确定性模板文本（保证报告永远能渲染）。
- 页面固定声明："本报告为风险教育内容，不构成投资建议"、"数字由计算引擎产生，AI 仅负责解释"。

## 7. 可靠性与错误态

- 服务端缓存行情（TTL 12 小时）：优先缓存 → 失败用过期缓存 → 无缓存时对预置资产启用**内置快照数据**进入"演示模式"（页面明确标注）。
- 错误态：无效代码（行内提示）、金额 ≤ 0、持仓数 <2 或 >8、某资产数据部分缺失（跳过并标注）。
- 断网演示路径：落地页一键示例组合 → 全部命中缓存或快照。

## 8. 技术选型

- Next.js（App Router、TypeScript）+ Tailwind；API Routes 承载数据获取、计算、AI 调用。
- LLM：GLM API，密钥走环境变量。
- 部署：Vercel 免费档。无数据库、无登录、纯无状态。
